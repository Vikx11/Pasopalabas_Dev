# Pasopalabas
Pasopalabas is a browser based 2D endless sidescroller 2-player racing game.
Whoever survives the longest wins!
Score points by surviving, dodging oncoming traffic, and picking up bonus crates.
Your vehicle can only take 3 hits and you will lose score upon colliding with an oncoming vehicle.
Your best score will be displayed on the leaderboard.

> [!IMPORTANT]
> How to setup:
> * Make sure you have XAMPP installed
> * Start Apache
> * Clone the repository
> * Have the repository placed in "xampp\htdocs"
> * Open your preferred browser and paste in this link: "http://localhost/Pasopalabas_Dev/GameWeb/"
> * Create accounts for Player 1 and Player 2
> * Enjoy the game.
>
> Controls:
> * W and S (Player 1)
> * Up and Down (Player 2)

> [!NOTE]
> You can register as either of these two types of Users :
> * Regular Player - You can play the game with this account.
> * Administrator - Have the ability to view, reset, and delete all accounts (type HESOYAM during registration).
